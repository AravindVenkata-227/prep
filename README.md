# Apple Interview Prep OS 🍏

A premium, fully interactive Single-Page Application (SPA) designed to track a 6-month software engineering interview preparation journey.

## Features
- **Local Persistence:** Automatically saves your daily task progress to your browser's `localStorage`.
- **Zero Backend Required:** Runs entirely in the browser using HTML, Tailwind CSS, and Vanilla JavaScript. 
- **Interactive Dashboard:** Tracks curriculum completion, mock interview trends, and daily execution tasks.

## How to Deploy to GitHub Pages

1. Upload the files from this directory (`index.html` and `README.md`) to a new, public GitHub repository.
2. In your repository, click on the **Settings** tab.
3. On the left sidebar, scroll down and click on **Pages**.
4. Under the "Build and deployment" section, set the **Source** dropdown to **Deploy from a branch**.
5. Under the **Branch** section, select `main` and keep the folder set to `/ (root)`.
6. Click **Save**.

Within a couple of minutes, GitHub will build the site and provide you with a live, shareable URL!
